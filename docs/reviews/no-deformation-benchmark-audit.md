# No-contour benchmark: independent scientific and accounting audit

The bounded four-arm benchmark is accepted at its stated complete-small-input scope. The review checked the protocol, native output association, measurement/extraction code, report tables, plotting recipe and reproduction cards. No integrator, estimator, root solver or sampling implementation was added by this audit, and no numerical run was duplicated.

The executable is release-built from scientific source `20bb812e31bc09a8a28a122d914a1de75e92cae7`; its SHA-256 is `7f41b135fdde78d89e443bf1372cb7d807e771ecb8bfd7fdf637143e82d64d36`. All 1,019 scientific source pins matched. The measurements use eight physical-core sibling groups, not reserved/exclusive host resources. Ordinary generation and integration are measured; this campaign does not repeat the independent normal/serial correctness matrix.

All 24 original integrations retain full-integral scope, complete production, eight complete shifts per sector, available uncertainty and the requested last-order native accuracy stop. The actual saved settings retain validated stability, no unstable cutoff, the stated tolerances, Kuo33002 and Korobov3. All native failure, unstable-point and cutoff-zero counts are zero. The complete bubble vectors through epsilon one contain six real/imaginary entries and 36 covariance entries; the two polynomial vectors through the finite order contain four entries and 16 covariance entries. Exact transcript checks included covariance symmetry, native SE/diagonal consistency, manifests, accepted/attempted work and per-sector shift inventories. Shared-sector replica covariance is retained directly rather than reconstructed from marginal sector estimates.

The graph bubble arms use the same graph, masses, kinematics and rGamma normalization. Their pole and finite values agree with the stated OneLOop-compatible reference. The two polynomial controls retain their independent imaginary-part references and exact pole cancellations. There is no supplied independent finite-real oracle for these polynomial cases, or analytic epsilon-one oracle for the bubble. The reported last-order joint SD is the square root of the covariance trace, a native RMS uncertainty summary, not a confidence radius or validated error bound. Near-roundoff uncertainty and the observed three-budget convergence curves must not be extrapolated into guarantees.

The methods have different sector counts: equal points per sector do not mean equal work. The report uses actual accepted sector-point totals and keeps both seed families separate. Shared seeds between bubble arms provide no recorded cross-arm covariance, so no calibrated difference significance follows from the marginal SEs. The observed checked cost and rescue fractions are explicit current limitations. Source and diagnostics establish root-callback evaluation and whole-vector precision replay, but do not profile their separate contributions to cost. Certified branch geometry does not turn tracked numerical evaluations into interval certificates.

Timing and memory attribution remain separate from the science. Native integration elapsed includes initialization, worker setup and checkpointing; it excludes artifact loading and the intervening contour pilot. These fields do not partition process wall time. Summed operational worker spans are not CPU or wall time; integrand spans include preparation and contain evaluator spans. The unweighted interior diagnostic, amortized QMC costs, mean sector cost and maximum sector mean are labelled distinctly; none measures maximum single-point latency.

The initial external observer's delayed polling/closure clock is not used as process wall time. The successor records launch-to-wait-observed completion, with the later exhaustive group scan excluded. All four generation repeats, 16 integration repeats and the pilot remain separately attributed. Native generation identities/layouts/settings agree with the originals; repeated integrations retain bit-identical complete estimates, covariance and manifests. Both final polynomial seeds are retained, including the slower sextic observation and its long scheduling gap. RSS is a sampled, non-simultaneous process sum with possible shared-page duplication; neither an exact unique-memory peak nor a strict lower bound is inferred. The faster observer detects generation peaks missed by the original coarse scan.

The report preserves native vectors and covariance, raw scientific versus repeat associations, source/executable identities, precision diagnostics and the contour pilot. All table values and the plot recipe were checked against the retained records. Reproduction cards change only graph/model path spelling; command-line overrides reproduce the measured settings. No arbitrary failure, missing estimate or unavailable uncertainty is relabelled as zero or success.

This acceptance does not establish no-contour ggHH/double-box performance, general singular-boundary resolution, a global BM center-selection driver, broader parameter-family support or an asymptotic performance advantage. The generic high-degree controls exercise complete regular-branch inputs. Native GCAD feasibility and a complete regularized physical artifact remain distinct future gates.

Private audit receipts retain exact source/output hashes and immutable copies of the audited compact summaries. The repository report and its compact JSON contain the reviewable published observations; raw build artifacts and benchmark output remain untracked.
