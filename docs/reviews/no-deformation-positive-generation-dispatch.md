# Positive-projective generation dispatch

The native generation facade now dispatches explicitly selected positive
homogeneous requests through their original source owner, automatic endpoint
proposals, complete family admission, symbolic Laurent continuation and the
existing universal artifact writer. This closes the native fresh/recovery/retry
connection; it does not complete the general resolution programme.

## Native ownership and reuse

An explicit `homogeneous_anchor` and complete `ordering = "given"` order select
the new route. The anchor is first in the original homogeneous coordinate order.
Fixed exact parametric sources use `PositiveProjectiveRequest`; genuine HEPKit
`GraphPoint` sources use that request's represented-graph constructor. Affine and
cube owners remain distinct enum variants, with their original serialized bytes.
There is no synthetic `GcadRequest` or conversion of reduced evidence into an
original homogeneous proof.

The dispatcher uses existing native staging codecs and symGCAD solve/verify
operations. Complete pair discovery calls the existing family issuer before
native symbolic subtraction and `ThresholdCompilationPlan` publication. It adds
no algebra, graph, root solver, derivative engine, worker pool or integration
loop. Existing full Laurent vector/covariance and native evaluator semantics
remain unchanged.

Saved positive requests retain the authentic anchor/order. Configuration replay
reconstructs default solver settings, so restoration validates the staged
request instead of demanding fresh caller flags or inserting unauthenticated
roles. Graph recovery requires the actual original point and an independent
conversion allowance. Completed recovery enforces its expected prepared
identity. An explicit resource-only retry creates a new recipe attempt and may
produce a new prepared identity while preserving original source, evidence and
configuration records. Cancellation and failures retain their native status.

## Scientific and executable checks

The private coherent generation suite passes 43 tests; three child harnesses are
ignored at top level and invoked by their parents where applicable. Four new
controls cover exact fresh/completed recovery, resource retry and interrupted
retry recovery, actual massive-sunrise GraphPoint fresh/recovered publication,
and wrong order/policy/cancellation refusal. Existing affine, cube, graph,
configuration-byte and retry regressions also pass. Strict feature and default
metadata Clippy checks and formatting pass. Independent source/API/recovery
reviews pass. The shared Cargo generation suite also passes all 43 tests (three
invoked child harnesses ignored at top level), in 82.20 seconds. Shared strict
core and CLI Clippy across all targets and formatting pass.

The actual native fixture keeps `mt=1`, `P(0)^2=16`, `D=4-2*eps` and measure
multiplier one. Fresh and recovered requests produce the same prepared identity,
seven source cells, 62 published sectors and Laurent orders -2 through zero.
The initial copied `P(1)` fixture refusal is preserved; the final fixture uses the
native independent momentum, dimension symbol and model scalar bindings.
These new archive roundtrips run in-process. The separate complete massive-sunrise
scientific control supplies cold-process restoration and full-vector comparisons
against fixed/dynamic contours and pySecDec; its seeds and timing remain separate.

## Remaining limits

Automatic discovery currently covers a fixed two-dimensional quadratic
pair/fold/ray class. The certified root/section issuer is broader and retains its
quartic and other higher-degree controls. Moving higher-degree towers, general
collisions, complete BM resolution and auxiliary-regulator continuation remain
outstanding. Unhandled proposals are typed refusals, never zero integrals.
Represented parametric/family positive routes and runtime parameter rebinding
are not admitted by this dispatcher.

The current graph-card CLI frontend uses HEPKit to prepare an exact parametric
integrand and enters the exact native facade. It does not claim the separate
strict `GraphPoint` recovery interface's original graph authority. Native graph
API tests retain that stronger owner independently.

The public [massive-sunrise card](../../examples/no_deformation/massive_sunrise.toml)
uses the explicit homogeneous anchor/order and Eager backend as a diagnostic
example. Actual ordinary and `--serial` CLI generation both pass with one worker:
62 sectors, the complete six-component Laurent layout and identical mathematical
content identity. Their CLI process times were 38.904 and 31.190 seconds
in the diagnostic debug executable. Metadata integrity checks pass for both;
a separate `inspect --deep --sector 0` process loads and validates exactly one
sector and its evaluator binary. These checks do not establish all four
integration scheduling combinations or an optimized ten-minute benchmark.
