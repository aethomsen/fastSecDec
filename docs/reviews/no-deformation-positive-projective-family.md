# Complete positive-projective paired endpoint families

This milestone adds a native two-dimensional endpoint-family constructor and
compact artifact restoration. It does **not** complete the general algebraic
resolver or either physical double-box calculation. The subsequent
[dispatch milestone](no-deformation-positive-generation-dispatch.md) connects
the supported automatic class to native and CLI generation.

## Source and mathematical authority

`ResolvedProjectivePairFamily::admit` consumes a genuine verified
`PositiveProjectiveQuotient`. Caller map proposals are untrusted: every original
cell must have a complete nonoverlapping partition, with interval/ray coverage,
positive orientation-adjusted Jacobians, the original selected root branches,
and all required closed-face unit certificates. Constant and paired moving
fibres support finite positive power maps and both positive-centre ray pieces.
Each accepted piece retains all four half-cubes and the native sector fans.

Root equations may have arbitrary degree within explicit resource limits. A
quartic control exercises the same issuer; there is no radical-only boundary
representation. This capability does not imply automatic discovery of arbitrary
higher-degree maps, nested towers or colliding roots. Unsupported geometry
remains an explicit incomplete result.

The constructor retains the complete original density, including every term,
complex polynomial numerator, regulator-dependent causal phase and meromorphic
Gamma prefactor. Source-factor rewrites must agree exactly in the admitted
algebraic relation. Numerator denominator clearing records its negative endpoint
powers; it cannot turn a singular factor into an unexplained smooth numerator.
Every accepted chart has closed-face unit evidence and a common endpoint
convergence strip. The original prefactor remains meromorphic; its poles are
excluded rather than certified analytic throughout that strip. Endpoint
continuation uses the existing Symbolica-based symbolic Taylor/IBP subtraction.
No numerical-dual endpoint reduction was added.

The initial denominator clearing uses conservative coordinate multidegrees.
Shared infinity factors can therefore be over-cleared and cause an honest
strip-admission refusal. Minimal valuations, arbitrary algebraic resolution and
general auxiliary-regulator cancellation remain required future work.

## Native reuse and runtime ownership

The implementation reuses Symbolica's algebraic coefficient domains, real-root
isolation and sign operations, polynomial collection and exact `quot_rem`,
symbolic differentiation, native evaluator callbacks and Atom codecs. Existing
FastSecDec endpoint/root programs and native sector maps remain their owners.
API/source inspection and focused executable tests cover these operations;
there is no replacement polynomial algebra, root solver, AD or serializer.

Artifact metadata version 8 stores chart-local root/map programs, original
source-factor links, numerator transport and endpoint evidence. It retains the
real positive-projective source owner during generation rather than grafting
the density onto an unrelated reduced GCAD request. Native source order and
CAD variable order are distinct and explicitly mapped. Version 7 restoration
and its wire representation remain supported.

Complete proof trees and source owners are generation-only. Tests require their
`Weak` handles to expire before local evaluator compilation, then restore
selected sectors in a fresh process. Mathematical identity excludes proof
resource limits and timing statistics; proof provenance remains inspectable.
Temporary symbol roles are alpha-normalized using existing native identity
facilities. The library still owns no scheduler or process pool.

artifact adapter. Maintained controls include a genuine quartic boundary,
nonconstant complex numerators on rays, complete regulated-density comparisons,
source/proof tampering, semantic identity, legacy restoration and fresh-process
selected loading. A separate named-order regression reverses the CAD order and
checks the original-coordinate numerator and selected branch equations.
