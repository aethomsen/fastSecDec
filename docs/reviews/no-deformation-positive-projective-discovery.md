# Automatic positive-projective map proposals

The native paired-family API now discovers proposals directly from its genuine
verified source. It returns the already-certified complete family, the proposals
and bounded failed-candidate history. It does not require physics-specific map
fixtures or perform a second round of certificate discovery after success.

The first sufficient automatic class is two-dimensional, constant-first CAD
with simple quadratic moving pairs and positive rays. Native coefficients and
discriminants locate collision endpoints. Two-ended power maps normalize the
pair; positive-centre folds cover both adjacent fibres, with complete dyadic
prefix partitions when needed. Neither topology names, expected cell counts nor
reference integral values choose the maps.

Symbolica performs univariate collection, resultants, differentiation,
coefficient content, `make_primitive`, flattening and exact quotient/remainder
operations. Public API/source inspection and a focused executable primitive
probe establish the reuse. Exact polynomial reconstruction checks every removed
content and factor rewrite. This is geometry orchestration, not a replacement
CAS or polynomial root solver.

Sampled exact signs help propose finite dyadic brackets only. The existing
issuer must still prove each whole closed box, select the original root, verify
all factor/Jacobian identities and full cell coverage, and establish the common
analytic strip. Cancellation, native failure and exhausted resources propagate;
they cannot become an accepted partial family or zero contribution.

Independent source/scientific/reuse review passed. Four new maintained controls
cover complete algebraic discovery and symbolic continuation, a different
one-cell source, cancellation/resource bounds, and explicit refusal of a
higher-degree automatic case while retaining the generic quartic issuer.
All nine new/inherited paired-family tests and 44 endpoint-transport tests pass
in the shared build. Strict core/all-target Clippy and formatting also pass.

On the actual massive-sunrise source, discovery admitted all seven original
cells and 62 closed endpoint charts in 12.60 seconds of an unoptimized native
probe, with a 43 MiB observed process peak. This starts from the saved original
proof and performs no solve or sampling. Three failed candidates remain
recorded. The accepted partitions have 1, 2, 1, 1, 1, 4 and 1 prefix pieces;
these counts are observed output, not algorithm assumptions.

This automatic class is narrower than the arbitrary-degree root evaluator and
certificate issuer. Nested algebraic towers, general collision resolution and
auxiliary-regulator continuation remain incomplete. Normal CLI/recovery routing
is the next integration milestone, and this probe is not an end-to-end
generation or performance benchmark.
