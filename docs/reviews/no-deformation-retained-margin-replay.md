# Reuse of retained native endpoint certificates

The endpoint-factor interface now accepts an untrusted `RetainedMargin`
proposal. It preserves the original native certificate bytes, named variable
frame and ordered domain constraints. `ClosedScalarChart` can request this
evidence for each internally derived factor and measure obligation instead of
repeating certificate discovery. Its existing discovery constructor is
unchanged.

Admission checks the actual issued chart's complete coordinate/root roles,
the exact native polynomial minus a strictly positive rational margin, and the
original certificate domain. The actual closed box must be contained in the
closure of that domain. Native verification proves the margin-subtracted
polynomial positive on the open domain; polynomial continuity then establishes
the required strictly positive margin on the contained closed box. A saved
sign, digest or matching display name is never sufficient.

This uses symGCAD's `Algebra`, `derive_domain` and `verify_certificate`,
Symbolica's existing polynomial conversion and exact equality, and the existing
bounded coordinate conversion. The only native-frame adjustment factors the
existing `Ring` constructor so it can preserve supplied names. The default
names and old conversion path remain unchanged. The certificate is not renamed,
rewritten or converted into a different proof format.

All stored certificate resource options must fit the caller's explicit replay
allowance before verification. Native validation retains its own hard ceilings.
Byte, degree, term, rational and cancellation limits still apply; the caller
must supervise wall time and aggregate RSS during long native calls. A decoded
certificate does not itself authorize a selected algebraic branch or complete
source-cell coverage.

The chart constructor still derives and checks the complete original scalar
density: source-factor links, epsilon powers, Gamma prefactor, causal phases,
root owner, measure and common strip. Coordinate-dependent physical numerators
remain outside this scalar constructor. Retained proofs cannot bypass that
restriction or turn the double-box's one-cell study into a complete integral.

API/source and focused native named-frame probes precede the small factoring.
Independent source, scientific, resource and ecosystem reviews passed. Focused
private controls cover nine factor/replay tests and three closed-chart tests,
including changed target/sign/margin, foreign roles, wider domains, reordered
constraints, invalid certificates and insufficient replay budgets. A genuine
issued scalar chart produces identical full-epsilon terms using fresh discovery
or retained evidence. An unrestricted unused native variable is also tested.

The shared consuming build passes all 44 endpoint-transport tests, including
the new retained-evidence controls, and nine paired-family/discovery tests.
Strict threshold-enabled core Clippy across all targets and formatting pass.

The fixed scalar and physical double-box requests have independently constructed,
byte-identical current native geometry problems while retaining different real
source identities and numerator inventories. A historical problem with different
settings remains distinct. This enables carefully checked geometry reuse; it
does not permit relabelling old evidence or claiming completed endpoint work.
