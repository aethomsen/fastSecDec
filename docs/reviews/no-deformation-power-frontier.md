# Auxiliary proofs in the physical resolution frontier

The caller-stepped `PhysicalChartFrontier` now optionally retains the complete
auxiliary principal-power inventory for each accepted physical chart. Its
ordinary constructors and physical progress retain their existing behavior;
auxiliary accounting is a separate opt-in operation.

Each first inventory comes from the issued original coefficient tree. Each
continued inventory follows the exact accepted physical map, retaining every
source level, support open and resulting open. No caller-supplied list can
replace that inventory. Active presentations, completed sources, absent power
normalizations and proved empty strict supports remain distinct. A completed
source remains at its owning frame; it is not transformed through a later
inadmissible center or interpreted as a zero physical contribution.

`Ready` means the auxiliary inventory is complete. It does not imply all
presentations are completed or all physical factors are resolved. The terminal
shortcut requires the existing proof that **all original local factors are
SNC**. A positive residual-cycle restart retains the retired inventory at its
exact source state and uses the genuinely new coefficient tree. Matching root
identities without the same source state and history are insufficient.

Preparation accepts one source slot at a time. Existing budget checks reserve
slot storage before allocation; checked counts and shared immutable request
vectors keep bookkeeping explicit. A resource refusal preserves the accepted
predecessor for retry. This is in-memory progress, not durable recovery or a
measured global memory bound. No scheduler, graph primitive, CAS, factorization
engine or integration API is duplicated.

The native original-tree constructor always emits at least one level. Each
level contributes at least one accounted slot, and continued groups preserve
that property. Review therefore rejected an unnecessary empty-request fallback
rather than inventing a new successful state for an unreachable construction.
