# Affine-projective normalized prefix review

The new `AffineNormalizedPrefix` owns an immutable prefix of an actual verified affine-projective CAD cell. It retains the original graph-derived source, CAD order, selected bounds and ancestor Arcs. It issues an independently selected constant interval followed by normalized moving upper sections; it does not issue a complete cell, density or integration kernel.

The shared normalization checker still uses native exact polynomial division and recombination for `P = M Q`, including a rational lower shift. Source association is checked against the original selected root and CAD delineation, with native range, endpoint-sign and derivative-margin certificates. The removed monomial is root-presentation data, not an additional physical factor power. The existing positive-projective entry points retain their original checked owners and semantics.

The evaluator reuses generic-degree `RootProgram` V3, native fixed-argument constant evaluation, `Scope` and `EvaluatorComposer`. Selected constants are owned callback results rather than caller inputs. Each section consumes previously admitted slots; no whole-density expansion, alternate root solver or custom differentiation was added. The compiled prefix retains its geometric owner. Native IR and scope restoration tests preserve arithmetic execution; detached serialized arithmetic alone cannot recreate source geometry authority. Cancellation, resource refusal and unsupported geometry remain distinct from successful issuance.

Independent review was split by authorship: the runtime agent reviewed admission, constant ownership and shared helper extraction; the producer independently reviewed the runtime agent's program and tests. The parent also reviewed the final source and sufficient-class boundaries. Final coherent execution passed all 74 map tests, including six new affine controls and seven inherited normalized controls. Workspace/all-target strict Clippy and formatting passed. New tests cover a genuine shifted cubic, independent exact rational selected fibers at 128/256 bits, nonzero composed derivatives, codec/lifetime/tracked-input behavior, source/role/selector refusal, resource/cancellation boundaries and the unsupported shifted-prior-prefix case.

The actual all-massive kite at the unchanged exact point p²=16 passed a separate source-bound diagnostic. One fresh native verification of the retained 9,840-cell proof was followed by generic issuance of the first constant interval, P160 and P165 in cell 0. No CAD solve was repeated. P160's exact identity is `P160 = p² Q160`; P165 needs no presentation monomial. The original selected bounds and full source prefix are retained. All 42 coordinate/partial-Jacobian comparisons and six additional P165 diagonal comparisons passed at 128/256 bits. Reference formulas were used only in this diagnostic, with exact-rational residual and tolerance checks. These debug diagnostic timings are not benchmark generation or integration timings.

The initial coefficient-chart class requires positive monomial parameter images. A nonzero lower shift is supported for the current section, but extending an arbitrary shifted tower is not yet admitted. Only Real selector domains are initially supported. The actual kite's fourth section P170 has a multiple-root boundary at `v3=v2=0, v0=3/4, v1=1/8`; successful P160/P165 prefixes do not remove that obstruction. Complete real cover, all-face physical factor/numerator/measure regularity, a common regulator strip and subtraction remain pending.

Reproducible local evidence is sealed under `target/no-deformation-affine-normalized-owner/`; independent reviews are under `target/no-deformation-affine-normalized-runtime-review/` and `target/no-deformation-affine-prefix-program/producer-review-r2/`. Failed compile/lint attempts and previous immutable source snapshots remain historical evidence. No raw proof or build artifact is tracked.
