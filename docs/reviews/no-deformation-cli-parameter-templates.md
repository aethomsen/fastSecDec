# Runtime threshold templates through the CLI

This milestone forwards explicitly declared runtime scalar roles to the existing
native threshold preparer. Graph inputs retain HEPKit kinematic symbols; direct
inputs can declare `direct.runtime_parameters`. Free symbols are never inferred
as runtime roles. Native source identity, chamber admission and preparation own
the mathematics. Runtime model masses and unsupported projective families still
receive their existing explicit refusals.

The CLI accepts the existing native V4 archive and uses the catalogue's checked
full bound-point identity when selectively loading exact contributions. It does
not manufacture that identity from a selected record. Unknown future archive
versions remain refused. Binding still uses the existing native parameter map,
and fixed/ordinary integration keeps its prior behavior. No new codec, guard,
algebra, graph representation, sampler or Python implementation is introduced.

## Scientific and recovery checks

The actual process matrix generates a native massive bubble template with
`m²=3`, `15<s<18`, once in each generation mode. Each archive is integrated at
`s=16` and `s=17`, in normal and serial modes: eight runs with 16,384 accepted
evaluations each. Every run retains all six real/imaginary Laurent components
through epsilon order one, their complete 6×6 covariance, three cells and four
endpoint charts. There are no failed evaluations or cutoff zeros.

The pole and finite coefficient agree with the independent B0 formula in the
native OneLOop rGamma normalization. The highest coefficient has a complete
vector/covariance parity check, not an independent analytic reference. Results
are bit-identical across generation schedules within the same integration mode.
Normal shared-shift and serial independent-sector designs agree under the
declared conservative error comparison; they are not the same statistical
design and are not asserted to be bit-identical.

Same-point checkpoints resume with changed worker counts. Different points are
rejected both by the CLI envelope and, separately, by native QMC/serial problem
identity checks. Missing, unknown, nonfinite and excluded parameter values leave
the artifact intact. A direct quintic tests a runtime role outside the unit cube.
Duplicate symbol aliases, integration/regulator collisions and simultaneous
fixed bindings are refused.

Fresh processes resume cancelled raw preparation and a partially compiled
journal. A retained native contribution's response hash and file identity prove
reuse across publication cleanup; completed publication is unchanged on resume.
Changed source, role or chamber constraints are refused. Historical fixed,
ordinary serial, contour and legacy settings controls pass.
