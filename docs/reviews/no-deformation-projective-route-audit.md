# Independent audit of the resolved projective route

The reviewed two-dimensional, fixed-kinematics route reuses native HEPKit
parametrization, symGCAD verification, Symbolica selected number fields,
polynomial division, sector fans, domain certificates, symbolic subtraction,
and the existing evaluator/compiler. No new algebra, graph representation,
root solver, numerical differentiation, worker pool, or artifact codec is
introduced. The owner and adapter pass this scoped source/API review.

## Source and geometric authority

`ResolvedProjectiveFamily` retains the original verified decomposition and its
preparation through shared owners. Each chart identifies an original cell,
its half-square and native fan sector, actual coordinate images and signed
orientation. Native division proves the monomial/residual identities. Signed
residual-minus-margin and positive-denominator certificates are replayed over
the whole unit box and an isolating interval for the selected primitive.
Continuity supplies the closed-boundary margin. Original leading denominators
remain obligations even when a simplified ratio cancels them.

The admitted first-axis endpoints are constant algebraic numbers. Native
`AlgebraicContext` joins their selected embeddings before coefficient algebra;
it does not treat two roots of the same polynomial as unrelated free slots.
Only `RootIndexDomain::Real` is currently accepted here. `Positive` and
`RealDescending` explicitly refuse; the implementation does not transplant
these ordinals into Symbolica's multiplicity-counted root convention.
Moving nonlinear sections, unbounded original axes, runtime kinematics, and
projective dimensions greater than two are outside this route.

The complete half-square/fan cover retains every original cell. The positive
measure includes each half scale and sector Jacobian once, while orientation
also accounts for the CAD-to-source coordinate permutation. Source factor
roles, exponents, monomial powers, prefactors and exact complex polynomial
numerators survive the map. Original verified causal signs generate the full
regulator-dependent phase before Laurent expansion. The common open regulator
strip and meromorphic witness precede the existing symbolic subtraction.
Arbitrary function numerators are not admitted by this sufficient class.

## Native graph input and represented values

The actual CLI route reads the unchanged native HEPKit graph/model/card,
constructs `GraphIntegral`, and obtains a native `ParametricIntegrand`. It then
calls the parametric threshold preparation API. Input-file fingerprints and
native parametric source identities are retained. This is a genuine graph
input path, but it does **not** invoke the separate strict pre-parametric
`GraphPoint` / `ExactRepresentedGraphInput` owner.

Card expression strings and integers are exact native expressions. A finite
TOML floating value is converted to its exact represented binary rational
before binding. Surviving Symbolica Float coefficients in rational geometry
are rejected by native conversion to QQ; this gate does not silently round or
rationalize them. The reviewed scalar triangle has exact mass overrides and
rational invariants, so no floating kinematic conversion is required.

This is not a blanket proof that arbitrary model Float data stayed exact before
HEPKit family arithmetic. When that stronger contract is requested, reuse the
existing `prepare_graph` / `resume_graph` and represented-graph admission before
family construction. A new graph type or algebraic conversion is unnecessary.
That interface extension is separate from the current exact scalar acceptance.

## Compiler, restoration and selective scope

`ContinuedSource::Projective` passes this actual owner into the shared Laurent
compiler. Its metadata records complete source cells, endpoint paths, original
factor associations, common strip, coordinate maps, orientation, and native
semantic identity. Plain deserialized lineage does not become a global proof
owner. A selected chart cannot report full-original-integral scope.

The detached `ThresholdPublicationPlan` writes the existing universal program
archive. The maintained preparation/recovery group passes 23 tests, including
verified replay without a new solve, numerical parity, and selected-sector
restoration through `ProgramArchiveReader` using the actual publication archive.
Two child-entry tests are invoked by their parent tests rather than by the
parent's ordinary test enumeration. The three owner tests also pass, including
complex density equality on every chart at two rational points and nonzero
regulator value, and exact signed-Jacobian identities.

There is a public serialization limitation to retain: a resident threshold
`KernelSet::to_bytes()` currently writes the monolithic native binary format;
the generic indexed writer refuses threshold partitioning. It is not a
substitute for the detached publication writer when selective loading is
needed. The tested CLI serial writer uses the supported publication route.
This limitation is explicit rather than inferred away from the successful
selective publication test.

The actual CLI triangle artifact is generated in one process and integrated
from its saved archive in another, with all 18 sectors represented. Its epsilon
zero value agrees with the existing native OneLOop reference. The small
acceptance run is not a ten-minute benchmark. Its normal stability/precision
rescue overhead remains part of checked sampling cost.

## Nonquadratic selected constants

A separate small native probe exercises `root(z^n-z-1,index)` for degrees
3, 4, 7 and 16, selecting the positive real root using the native convention.
It verifies exact field relations, evaluates the real root and a complex
coefficient expression at f64 and 128/256 bits, and compares against native
exact isolated-root enclosures. A second process decodes the exact evaluator
with the same native serde-bincode codec and repeats these checks. Both
processes pass (about four seconds each). Leaf dependency hashes match before
and after the build; no new dependency or FastSecDec source is compiled.

An initial JSON-only evaluator roundtrip failed because its borrowed-byte
serde payload requires the native binary codec; that failed probe and the
corrected native-codec run are both retained. This is not a production codec
failure. The successful probe establishes native constant-field evaluator
capability beyond quadratic examples. It does not establish a degree-16
complete projective family, moving-root continuation, every selector domain,
or general endpoint resolution.

## Next reusable extension

After the triangle and massless sunrise, the three-dimensional massive box is
the next useful scalar target. Its exact source suggests a constant algebraic
first transition followed by rational-linear prefix/fiber bounds. First obtain
the complete native CAD bound/order inventory. If that shape is confirmed,
extend the existing source-owned triangular map loop, complete half-cube/fan
cover, original-factor ledger and closed-margin checks to the additional
prefix axis. Keep the native bound inventory authoritative; do not encode the
box polynomial, cell count or analytic transition formula into production.

A moving high-degree bound would instead require the existing selected-section
and normalized-root ownership machinery and closed-face resolution. Raising a
constant-field degree limit alone does not provide that authority. Higher-loop
kite and physical double-box closure remain separate incomplete work.

Private immutable evidence is indexed by
`target/no-deformation-resolved-route-audit/review.json`; the native constant
probe is under its `nonquadratic/` directory. No costly benchmark or physical
proof was rerun for this audit.
