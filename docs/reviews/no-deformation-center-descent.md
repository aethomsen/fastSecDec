# Center descent on an actual ambient open cover

This construction verifies compatible local monomial centers on a principal-open
cover of one immutable ambient problem. Its result is a glued admissible center.
It does not assert that the global Bierstone–Milman invariant selected it.

The distinction follows the published algorithm:
[Bierstone–Milman 2008, Sections 7.1–7.2](https://ems.press/content/serial-article-files/41043)
uses lower-dimensional functorial resolution to obtain compatible local
sequences, and selects centers using `(inv, J)`. The auxiliary `mu` participates
in the progress argument. Local admissibility alone supplies neither that
selection nor termination.

## Native construction and exact overlaps

`PrincipalCenterAtlas` consumes one actual history, marked source and native
principal-open cover of the entire ambient. A cover only of a contact support
is refused. Existing native localization constructs each open and retains
certified empty entries. Every boundary equation, ID, birth and old-history
snapshot comes from that same source history.

Local centers are issued by the existing monomial producer on the actual
restricted source. Alternative ideal generators require native two-way ideal
equality. Empty cosupport and empty ambient entries are explicit. Matching
dimensions, samples or generator names cannot supply this authority.

Each pair is checked in the existing native common-frame construction, using
the full ambient equations and all inverse relations. No contact equation is
added to make centers agree. The added determinant inverse is already a unit
on the child open, so this construction does not secretly shrink the
intersection. Native ideal membership checks both inclusions after transport.
The existing prepared-membership helper is reused within each directional
batch.

Triple consistency here follows from principal localization over the same
ambient: adjoining the inverses of the same open functions commutes, and all
maps fix the common source coordinates. This is not a general overlap theorem
for unrelated implicit presentations. Likewise, boundary equations agree
exactly, with unit ratio one, because they are localizations of the same actual
history. Arbitrary global divisor-event reconciliation remains pending.

The final owner checks every actual center/open association and every pair,
including empty intersections. Reordered completed work is accepted; missing
or duplicate entries are refused. These immutable owners introduce no new CAS,
graph representation, integration scheduler or numerical sampling.

## Scientific controls and limits

The native monomial `(y^2*z^3, 2)` control uses `D(x)` and `D(1-x)` and the
existing fixed boundary-incidence order. Both actual producers select the
same `y` center. A unit-scaled `x*y` presentation on `D(x)` is accepted.
Controls retain zero opens, a disconnected ambient with an empty intersection,
and a three-open cover with every pair. Different local maxima that disagree
on the overlap are refused rather than promoted to a global step.

Additional mutations cover omitted inventory, wrong source/history, swapped
boundary-label owners, altered centers, support-only coverage and insufficient
resource budgets. Empty-cosupport controls preserve their native proof. Object
release and retry tests concern ownership; they are not an aggregate RSS bound.

Independent producer and coordinator source reviews accept this limited
construction. The frozen seven-file handoff has SHA-256
`2ccd740b4ce26381fd19b6a77d7ad3b322d9cc74b0413170bf8c0036e0a0b810`.
Its native diagnostic snapshot passed 126 resolver controls, including six new
groups, plus strict library/test lint checks. Substantive files are imported
unchanged; only the two parent module exports are assembled with the independent
physical-lineage slice. The consuming gate below uses the adopted dependency
graph, separately from that diagnostic build.

The constructor currently returns complete local objects or a
resource refusal; it is not a durable resumable atlas producer. Generic
invariant stratification, arbitrary ambient overlaps, parameter specialization,
global blow-up commitment and real integration ownership remain required work.
