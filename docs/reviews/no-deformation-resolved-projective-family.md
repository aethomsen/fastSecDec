# Complete resolved projective families

This route retains every cell of a freshly verified, fixed, two-dimensional
`AffineProjective` request. Its present sufficient class has constant algebraic
bounds on the first CAD axis and rational linear bounds on the last axis. It
retains the original request, preparation, cell ordinals, polynomial identities,
and root selectors. It does not reclassify an affine source as a native cube or
as a secant family.

The native massive triangle control has `U = 1` and `F = 1 - 5 x0 x2` after
eliminating the middle projective coordinate. Native GCAD returns four cells:
two outer positive cells, an inner positive cell, and an inner negative cell.
The two prefix transitions are the selected real roots of
`1 - 5 y + 5 y²`. Symbolica's `AlgebraicContext` joins these selected embeddings
before any coefficient arithmetic; their relations are not assumed from two
independent copies of the defining polynomial.

Each original cell is mapped to a square using its actual bounds. All four
half-squares are retained, with upper halves reflected toward their corners.
The existing native sector decomposition produces a complete fan on each half.
The owner retains each half/fan path, full prepared-coordinate images, and the
positive measure. Signed orientation includes the CAD-to-preparation
permutation, reflections, and the native matrix determinant. The measure
contains each half scale and sector Jacobian exactly once.

Native polynomial division extracts the monomial orders. Every remaining
numerator, denominator, measure factor, and original leading denominator gets
a replayed symGCAD positive-margin certificate over the whole unit cube and a
certified interval for the selected algebraic primitive. Polynomial continuity
extends these bounds to the closed faces. Original leading denominators remain
in the receipt inventory even if rational simplification cancels them.

The scalar triangle produces **18 complete endpoint charts**. The source-only
native atlas probe found and replayed all **108** requested residual margins in
0.100 s, after a 0.005 s native solve and 0.001 s independent verification. These
are small native probe timings, not generation or integration benchmarks.

The density keeps every source term's monomial powers, exact complex polynomial
numerator, prefactor, and factor exponents. The original verified causal sign
supplies the full regulator-dependent phase before expansion. A common open
regulator strip and a native meromorphic witness are required before the
existing `threshold_subtract` continuation and shared Laurent compiler run.
No per-cell epsilon-zero substitution is used. Arbitrary function numerators
and runtime kinematic parameters remain outside this owner class.

`ResolvedEndpointV1` is a distinct artifact descriptor for these full maps.
The shared compiler retains original cell coverage and endpoint paths;
selectively loaded charts cannot claim the full original integral.
